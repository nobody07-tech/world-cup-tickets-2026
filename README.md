# World Cup 2026 Ticket Sales Website

Bienvenue sur le projet de site de vente de billets pour la Coupe du Monde 2026 aux USA.

## Fonctionnalités
- **Vrais Matchs :** Données réelles des villes hôtes américaines.
- **Paiement Flexible :** Simulation Orange Money et Carte Bancaire.
- **Contact WhatsApp :** Bouton direct vers le support client (+1 410 405 3591).
- **Design Pro :** Interface inspirée par le style officiel FIFA.

## Installation Locale
1. Clonez ce dépôt.
2. Ouvrez `index.html` dans votre navigateur.

## Comment mettre en ligne (Hébergement)
Pour que tout le monde puisse voir ton site :
1. Crée un nouveau dépôt vide sur ton GitHub nommé `world-cup-tickets-2026`.
2. Ouvre un terminal dans ce dossier et tape :
   ```bash
   git remote add origin https://github.com/TON_PSEUDO/world-cup-tickets-2026.git
   git branch -M main
   git push -u origin main
   ```
3. Sur GitHub, va dans **Settings > Pages**.
4. Sous **Build and deployment**, choisis la branche `main` et clique sur **Save**.
5. Ton site sera en ligne à l'adresse : `https://TON_PSEUDO.github.io/world-cup-tickets-2026/`
